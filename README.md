# Roommate Compatibility Scorer

## About the Project

The Roommate Compatibility Scorer is a Python-based project designed to evaluate compatibility between students who want to share a room or accommodation.

It aims to compare students' daily routines, lifestyle preferences, and study habits to help them identify potential roommates with compatible lifestyles.

## Project Objectives

* Compare students' daily routines.
* Evaluate study habits and college schedules.
* Consider sleep schedules and noise preferences.
* Calculate a compatibility score based on the implemented scoring logic.
* Help students make more informed roommate choices.
